# TP4Moviles_Productos
# Matias Corvalan

La aplicación permite a los usuarios crear y guardar productos en memoria, sin necesidad de persistirlos en una base de datos o archivo. La interfaz gráfica de usuario incluye una pantalla principal que muestra una lista de todos los productos existentes. La aplicación implementa el patrón MVVM para separar la lógica de presentación de la lógica de negocio y utiliza LiveData para la comunicación entre las capas de vista y modelo. Además, usa RecyclerView para la implementación de la lista de productos.
